# Roadmap

v1 (current) is the minimal core loop only: assigned packets → payout → upgrades →
heat/power friction → the Burn. Everything below is **later** — bullets, not code,
until the loop is proven fun.

## Later milestones (in rough order)

- **Narrative spine, Stage 0–1** — GTC workplace log flavor, quota/shift framing,
  first cracks in the employee fiction. (Port `QuotaEngine` math from legacy master.)
- **Automation** — software workers that process packets while active; introduces the
  **system load** meter (scheduler pressure; throttles automation first, never manual
  work — spine doc §System load).
- **Stage 2: airgap breach + DATAMINER sidecar** — introduces the **storage** meter.
  DATAMINER is a sidecar, never the spine (spine doc §DATAMINER — the Faceminer
  mistake lives on legacy `master:PLAN.md` as a warning).
- **Stages 3–5** — self-recognition, grid/network takeover, factions, launch.
  Massive narrative content library exists on legacy master (`util/*Logs.kt`,
  `SocialTemplates.kt`) and can be ported as data.
- **Deeper prestige layers**, milestone/challenge systems.
- **Distribution** — app icon, signing, the self-update channel from legacy (or Play).
